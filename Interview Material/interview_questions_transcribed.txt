Standard Interview Introduction Framework
-----------------------------------------
Professional Snapshot (15–20 sec)
- Name & total experience (Mention experience by data stack, not only total years)
- Current role and specialization (Align your role title to the interview)

Example:
I'm a Databricks and Azure Data Engineer with 7 years of experience, including 4+ years working on Databricks, PySpark, and Azure data platforms.

Core Skill Stack (30–40 sec)
- Mention only skills relevant to the role.

Data Engineering:
- Databricks
- ADF
- Delta Lake
- Performance tuning
- Medallion Architecture
- Notebook optimization

Azure / Fabric:
- ADF
- ADLS Gen2
- Synapse
- Fabric Lakehouse
- OneLake
- DirectLake

Programming:
- Python
- PySpark
- Spark SQL
- SQL

Project Experience (40–50 sec) — Context → Action → Impact
- Mention maximum 2 projects
- Quantify results where possible

Example:
In a retail analytics project, I built ADF-orchestrated Databricks pipelines processing ~3 TB/day. By optimizing Spark jobs and implementing incremental loads, we reduced pipeline runtime by 35% and improved reporting SLAs.

Role Alignment Closing (10–15 sec)
- Explicitly connect your experience to the project role for which you are giving the interview.

Example:
Given my hands-on experience with Databricks, Azure orchestration, and scalable data pipelines, I believe I'm a strong fit for this role.
